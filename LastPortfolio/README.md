# SRI.ARCHIVE

A restrained, responsive portfolio presented as a digital survival archive for the GDG Silicon Maze “The Last Portfolio” task.

## Features

- Survivor identity and readable archive-style about log
- Categorized technical arsenal
- Two project archive records: Groundwater Monitoring and AeroNITK Web/Admin
- Responsive navigation with a mobile menu
- Contact/final transmission links with clearly marked placeholders
- No framework or build step required; fast static HTML/CSS/JS

## Run locally

Open `index.html` directly, or serve the folder with any static server:

```bash
python -m http.server 8080
```

Then visit `http://localhost:8080`.

## Personalize before deployment

Replace `[YOUR EMAIL]`, `[YOUR GITHUB]`, and `[YOUR LINKEDIN]` in `index.html`. Replace the two archive visual placeholders with real screenshots when available, and update each project link. No fabricated achievements or statistics are included.
